# آرتیکل کوییز ۱ — کپشن اینستاگرام

## متن پست

چندتا رو درست گفتی؟ 👇

آرتیکل آلمانی حفظ‌کردنی نیست — **قانون‌ داره.** این ۵ تا رو یاد بگیری، هزارتا کلمه رو بدون فکر درست می‌گی:

🔹 ‎-chen‎ → همیشه **das**
🔹 ‎-ung‎ → همیشه **die**
🔹 ‎-ling‎ → همیشه **der**
🔹 ‎-schaft‎ → همیشه **die**
🔹 ‎-um‎ → همیشه **das**

اون اولی جاییه که همه گیر می‌کنن: **das Mädchen** — «دختر»، ولی آرتیکلش خنثیه. چون قانونِ پسوند از معنی قوی‌تره.

تعداد درست‌هاتو کامنت کن ✍️
و بفرستش برای اون رفیقت که همیشه der و die رو قاطی می‌کنه 📩

ذخیره‌ش کن که دفعه‌ی بعد یادت بیاد 🔖
